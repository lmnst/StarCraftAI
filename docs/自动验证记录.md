StarterBot 自动采矿、增加工人并完成水晶塔，人口上限由9增加至17。
UAlbertaBot 自动发展经济、建造兵营并生产狂热者；已在实际游戏窗口核对运行画面。
单位与建筑数量按程序已拥有的对象计数，包含训练或建造中的对象。

本次验证是两个程序分别对游戏内置电脑进行的独立运行测试，不是两个C++程序之间的对战，也未统计完整比赛胜率。

## 使用入口

启动器：E:\StarCraftAI\tools\LocalDemoLauncher.exe

- Run StarterBot：重新启动教学程序。
- Run UAlbertaBot：重新启动比赛程序。
- Stop demo：停止此启动器创建的演示进程。
- 关闭启动器也会关闭它创建的游戏和程序。

当前保留UAlbertaBot游戏运行。再次启动会从头开始并覆盖对应的实时CSV；本轮验证的CSV已另外保存。
